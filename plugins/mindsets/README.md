# mindsets

Operating-mode skills that re-trigger the right cognitive stance for a session: researcher (generative exploration), mechanic (keep-alive / operator execution discipline), wingman (codex co-researcher collaboration), and bakeoff (undirected multi-entrant competitions for idea mining).

Included skills: bakeoff, researcher, grill-me, mechanic, wingman. Enable the plugin in a skill-capable host; no MCP server or executable is required.

## Standalone use and license

This directory is an independent plugin root. Enable it in your plugin host.
Owned code and content are MIT licensed; third-party terms remain in
`THIRD_PARTY_NOTICES.md`. Provider requirements are declared in `providers.json`.

Validate the installed skill/agent entrypoints with `python3 test_package.py`.

The wingman/co-researcher workflow optionally uses a host-installed Codex CLI and
account, which may use a subscription or usage billing. If unavailable, report
that limitation and continue other local mindset modes; keep solo research
conclusions provisional. No provider is required to read or use the other skills.
